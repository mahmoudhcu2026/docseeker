لماذا DocSeeker؟

Why DocSeeker?

يبحث داخل الملفات

Searches inside files

Word وPowerPoint وExcel وPDF والملفات النصية، وليس الأسماء فقط. تظهر النتائج أثناء الكتابة.

Word, PowerPoint, Excel, PDF and text files, not just file names. Results appear as you type.

بحث عربي ذكي

Smart Arabic search

يتجاهل التشكيل واختلاف أ/ا/إ وة/ه وى/ي و«ال». البحث عن «عامل» يجد «العاملين».

Ignores diacritics and أ/ا/إ, ة/ه, ى/ي and «ال» differences. Searching عامل also finds العاملين.

Works offline, uploads nothing, no accounts, no ads. Cloud-only OneDrive files are never downloaded.

طريقة التثبيت

How to install

  1. الطريقة الأسهل: اضغط زر احصل عليه من Microsoft أعلاه ثم تثبيت في متجر Microsoft. يُثبَّت البرنامج دون أي رسائل تحذير ويتحدث تلقائياً.

أو التثبيت من الملف المضغوط:

  1. اضغط نزّل ملف التثبيت مباشرة أعلاه، فيُحفظ الملف المضغوط في مجلد «التنزيلات».
  2. اضغط على الملف بالزر الأيمن واختر استخراج الكل (Extract All).
  3. افتح المجلد الناتج وانقر نقراً مزدوجاً على DocSeeker-Setup.exe.
  4. إذا ظهرت نافذة زرقاء بعنوان «Windows protected your PC» فاضغط More info ثم Run anyway.
  5. اضغط Next ثم Install ثم Finish. اختر المجلدات أو «كل الأقراص» وابدأ البحث.
  1. Easiest: click Get it from Microsoft above, then Install in the Microsoft Store. It installs with no warnings and updates automatically.

Or install from the zip file:

  1. Click download the installer directly above. The zip file is saved to your Downloads folder.
  2. Right-click the file and choose Extract All.
  3. Open the extracted folder and double-click DocSeeker-Setup.exe.
  4. If a blue window says "Windows protected your PC", click More info, then Run anyway.
  5. Click Next, Install, then Finish. Choose your folders or "All drives" and start searching.
في طريقة الملف المضغوط فقط: تظهر النافذة الزرقاء لأي برنامج جديد غير مسجّل لدى Microsoft بعد، ولا تعني وجود خطر. البرنامج لا يحتاج إلى صلاحيات المسؤول ويُثبَّت لحسابك فقط.
Zip file only: the blue window appears for any new program not yet registered with Microsoft; it does not mean anything is wrong. DocSeeker needs no administrator rights and installs for your account only.

خصوصيتك

Your privacy

  • يُحفظ الفهرس والإعدادات وسجل البحث على جهازك فقط.
  • لا يُرسل أي ملف أو اسم ملف أو كلمة بحث إلى أي جهة، ولا يوجد تتبع ولا إعلانات.
  • الاتصال الوحيد بالإنترنت هو البحث عن إصدار جديد، وفتح واتساب أو تيليجرام أو Gmail عندما تختار المشاركة بنفسك.
  • The index, settings and search history stay on your computer only.
  • No file, file name or search word is ever sent anywhere. No tracking, no ads.
  • The only internet use is checking for a new version, and opening WhatsApp, Telegram or Gmail when you choose to share.
